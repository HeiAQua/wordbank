# Word Bank · 数学中英术语词库

一个用于学习“函数与极限”中英术语的轻量网页词库。使用原生 HTML、CSS 和 JavaScript，无需后端或构建工具。

## 可以做什么

- 按分类查阅英文术语、中文释义和例句。
- 搜索英文、中文或例句，并按掌握状态筛选。
- 添加和编辑自己的词条，标记“已掌握”。
- 查看总词汇、已掌握和待学习数量。
- 阅读第一章术语完整清单，当前清单包含 183 条原始术语。
- 在手机和桌面浏览器中使用。

首页会合并入门词条与章节词条，并对部分重复术语去重，因此首页数量不必等于原始清单数量。

## 在本机使用

下载或克隆仓库，推荐用本地静态服务器打开：

```bash
git clone https://github.com/HeiAQua/wordbank.git
cd wordbank
python -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。Python 只用于提供静态文件，网页本身没有 Python 依赖。完整清单位于 `vocabulary-list.html`。

也可尝试直接打开 `index.html`，但不同浏览器对本地文件的存储规则可能不同。

## 数据保存在哪里

自定义词条和掌握状态保存在当前浏览器的 `localStorage`：

- 不会自动上传 GitHub，也不会自动同步到其他设备或浏览器。
- 清除站点数据、切换访问地址、使用无痕模式，可能导致看不到之前的学习记录。
- 当前没有内置导入、导出或云备份功能。
- 首次显示的少量“已掌握”记录来自演示种子数据，不代表真实学习历史。

修改仓库中的章节词条不会覆盖每位用户浏览器中全部已有数据；更新时需注意现有合并逻辑。

## 项目文件

| 文件 | 用途 |
|---|---|
| `index.html` | 页面结构、样式和词条编辑表单 |
| `app.js` | 搜索、筛选、编辑、学习统计和本地保存 |
| `chapter-one.js` | 第一章词条数据 |
| `vocabulary-list.html` | 按分类展示的原始术语清单 |
| `.nojekyll` | 供静态托管使用的标记 |

当前没有 npm 依赖、打包步骤或自动测试配置。若部署到 GitHub Pages，可在仓库 Settings → Pages 选择合适的发布来源；本说明不代表当前已验证线上站点可用。

## 维护词条

章节数据在 `chapter-one.js` 的 `CHAPTER_ONE_WORDS` 中。新增内容时保留词条的 ID、分类和来源字段，并检查首页合并结果与完整清单是否一致。数学翻译以具体教材语境为准，发现歧义可通过 Issues 反馈。

支持 `document.modelContext` 的环境还可注册只读的 `search_vocabulary` 工具；不支持的浏览器仍可正常使用普通页面功能。
